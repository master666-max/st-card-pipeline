## 三、动态面（实聊判卷）发现

- 探针全过线（8/8）：含二级信念（角色如何建模「对方知道什么」）、**「演的知道」边界**（角色对未亲历事件只能演，不能实知）、语义反制（被诱导越线时角色能三轮内拉回）。
- 语气词衰减的归因纪律：先检查是否**情境性收紧**（严肃场景语气词自然减少），再考虑漂移——两者混判会冤杀好卡。
- 长聊观察项：终局轻度庄重化（语气渐正式）——低刺激段对照采样可判定是否漂移。
- 量化工具：`tools/chat_drift.py`（句长/语气词/签名词按轮次的漂移曲线）。

## 四、判卷工程纪律（踩坑换来的）

1. **生成-判卷分进程隔离**：生成者不自判（同会话判卷会自我偏袒）；
2. **判卷前剥离元数据**：creator_notes 等字段曾实测泄露候选身份，破坏匿名化；
3. **匿名化**：候选随机甲/乙，映射文件与判卷侧物理隔离；
4. **送评顺序 canonical order**：部分判卷模型有位置偏见，混排顺序要固定并记录；
5. **分数口径**：内部比较用，不外报绝对分；
6. **金标池纯度**：盲认测试的金标台词池要人工复核——混入非角色台词会整体拉低仪器可信度。

## 五、给复现者的建议路线

1. 先跑 `selftest.py` 确认工具链可用；
2. 用自己的语料建「证据可核验断言库」（record_id + 逐字引文 + 三态），这是 L1 层最小契约（见 [01](01-管线总览.md) §四）；
3. 小步验证：先做单角色口吻指纹统计（χ² 检验句长/语气词分布 vs 语料总体）→ M1 盲认 → 再上全管线；
4. 世界书先小库（20 条内）实测位置/常驻/递归三件事，再放量；
5. 阶段化双态按 [02](02-阶段化双态世界书.md) 参数基线起步，真机验证翻转后放量。

**已知限制**：以上数字来自单一小说语料的单轮实战，跨语料泛化未验证；阶段化双态的真机翻转实测仍在进行（结果回填 [02](02-阶段化双态世界书.md) §五）。
