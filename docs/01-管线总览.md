# 01 · 管线总览：从长篇小说语料到 SillyTavern 角色卡/世界书

> 本仓的方法论总纲。实战验证语料：一部 517 章、约 550 万字的长篇小说全本（含逐字引文回链的正典库）。本文只讲方法，不含任何上游语料内容。

## 〇、第一性原理（五条）

1. **L0 原文 ⊕ L1 正典双层资材**：结构化整理层（正典库，每条断言可回链原文引文）负责「导航与查询」，原文语料负责「模仿与口吻」。只查不读，角色说话没有质感；只读不查，事实会飘。
2. **卡是分布参数，不是资料库**：角色卡的预算守恒——描述、示例对话、世界书共享同一个上下文预算。杠杆率：**示例对话 ＞ 指令 ＞ 标签化断言**。往卡里塞资料不会让它更像人，会挤掉它「表演」的空间。
3. **人的定义**：自洽 + 缺陷 + 议程 + 具体 + 时间性。五个都不能缺——没有议程的角色只是背景板，没有缺陷的角色只是说明书。
4. **正典 / 归纳 / 创作三层分界**：每个可生成资产都标注来源层。正典=原文断言忠实压缩；归纳=多断言的模式总结；创作=正典之外的合理外推。判卷时按层核查，创作层冒充正典层是严重事故。
5. **生成者不自判**：生成角色卡的会话/进程不得同时担任判卷者。判卷刻度从轻到严：同批 A/B 对照 → 植株抽样考试 → 独立验证轮封顶。

## 一、七阶段生成管线

`L0 原文语料 ⊕ L1 正典库 → ST 角色卡 + 世界书`

| 阶段 | 做什么 | 输入 → 输出 | 质量门 |
|---|---|---|---|
| ① 素材汇编 | 本地双通道（零/低 API）：正典断言按角色聚合 + 原文口吻语料抽样 | 库目录 → 素材包 | 引文回链率 100%；归属歧义显式标注 |
| ② 人设档案 | 压缩归纳（H2 主战场）：全量断言 → 固定预算人设档案 | 素材包 → 档案 | 预算硬上限；关键事实抽样回核 |
| ③ 口吻规格 | 统计 + 归纳（H1 主战场）：句长分布/语气词密度/签名式/句式指纹 | 对话语料 → 口吻规格 | 指纹统计显著（实战 χ²=98.5）；M1 盲认 ≥ 线 |
| ④ 卡体 | 预算守恒：八静槽（名称/档案/人格/场景/开場白/示例对话/系统/后史指令） | 档案+口吻 → card JSON | token 账目逐槽可查 |
| ⑤ 对话层 | 杠杆率优先：示例对话 ＞ 描述性指令 ＞ 标签化断言 | 口吻规格 → mes_example | 示例对话逐句可溯源或标创作层 |
| ⑥ 世界书 | 角色专属 + 共通三库（见 [03](03-共通与专属分库.md)）；剧情状态用阶段化双态（见 [02](02-阶段化双态世界书.md)） | 断言库 → worldbook | keys 碰撞扫描；前缀陷阱检查；预算账 |
| ⑦ 互审精修·装配 | 忠实性对账 + 独立判卷 + PNG 打包回归（v2/v3 双 chunk 三关） | 全部产物 → 发布件 | 判卷过线；回读三关 PASS |

**断点续传**：每阶段物料化落盘（中间产物即契约），重跑只补差异。**降级路线**：任何阶段质量门不过都有三档出口（降级产出+显式标注 / 人工介入 / 打回上游），不存在静默降级。

## 二、三层标注机制（`extensions.x_canonlay`）

卡与条目的 extensions 里带来源层标注：

```json
{"x_canonlay": {"layer": "canonical|inductive|creative", "sources": [{"record_id": "...", "chapter": 27}]}}
```

- `canonical`：原文断言忠实压缩，引文逐字可回链；
- `inductive`：多断言归纳出的模式（判卷口径宽松于 canonical）；
- `creative`：创作外推（必须显式标出，不得与正典混淆）。

## 三、判卷仪器一览

| 仪器 | 做法 | 线 |
|---|---|---|
| M1 盲认测试 | 生成台词混入金标台词池，判卷员分辨真伪 | 显著高于 50% 抛硬币线（实战修复后 62.5%） |
| E 量表 | 七维评分（E1-E4 门槛维 + E5-E7 观察维） | 门槛维任一 ≤2 判死 |
| 动态面协议 | 实聊多轮 + 漂移量化（句长/语气词/签名词按轮次） | 探针全过线 + 首跌轮次（TFD）记录 |
| 匿名化纪律 | 候选卡随机甲/乙（映射与判卷侧物理隔离） | 判卷结束前不披露映射 |

**判卷红线**：生成与判卷分进程/分会话隔离；判卷前剥离 creator_notes 等元数据（曾实测元数据泄露匿名性）；送评顺序 canonical order（某些判卷模型有位置偏见）；分数只作内部比较。

## 四、上游数据形态（可复用的最小契约）

本项目不附带上游语料，但管线对上游只有一个最小契约——**证据可核验的断言记录**：

```json
{
  "record_id": "cand-<类型>-<哈希>",
  "library": "character|event|relation|foreshadow|setting|timeline",
  "canonical": {"...按类型不同的断言..."},
  "evidence": [{"vol": 1, "chapter": 27, "line": 237, "quote": "原文逐字引文"}]
}
```

三态质量分级（confirmed ✅ / provisional ◐ / quarantine ⚠）随行标注：confirmed 直接作「正典事实」；provisional 可用作「机器参考」并标注；quarantine 隔离待人工。
